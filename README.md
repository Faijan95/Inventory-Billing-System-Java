# Inventory Billing System Java

## Project Overview
Inventory Billing System is a console-based Java application developed using Object-Oriented Programming and File Handling concepts.

This project helps shop owners or inventory managers to add items, view stock details, and generate bills efficiently.

---

## Features

- Add New Item
- View All Items
- Generate Bill
- Quantity Management
- Data Stored in Text File
- Persistent File Handling Support

---

## Technologies Used

- Java
- OOP Concepts
- File Handling
- VS Code

---

## Files Included

- item.java
- inventory.java
- filemanager.java
- main.java
- items.txt
